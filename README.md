## Quick examples / Exemplos rápidos

| Pattern | EN | PT |
|---------|----|----|
| `^\d+$` | Digits only | Só dígitos |
| `^[A-Za-z]+$` | Letters only | Só letras |
| `\b\w+@\w+\.\w+\b` | Simple email-ish | Email simples |

**EN:** Always test regex against real inputs; flavors differ (JS, Python, PCRE).

**PT:** Testa sempre a regex com dados reais; os dialects diferem (JS, Python, PCRE).
