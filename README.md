## Install / Instalação

### 1) Clone / Clona

```bash
git clone https://github.com/manansbdb/regex-cheatsheet.git
cd regex-cheatsheet
```

### 2) Copy / Copia

```bash
mkdir -p docs
cp PATTERNS.md docs/regex-patterns.md
```

### Requirements / Requisitos

- `git`
- No runtime dependencies
